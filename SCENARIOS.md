# Сценарии использования веб-приложения Necromunda Gang Wars

## Обзор проекта

Веб-приложение для управления бандами, ведения кампаний и организации игрового процесса в настольной игре **Necromunda: Gang Wars**. Приложение рассчитано на группу игроков (2–8 человек), ведущих совместную кампанию, а также на одиночных игроков, желающих управлять своей бандой и строить ростеры.

Ключевые принципы:
- Все данные (составы банд, оружие, навыки, аксессуары) строго соответствуют официальным правилам
- Каждой банде доступны только разрешённые для неё типы бойцов
- Каждому бойцу доступно только разрешённое для него снаряжение
- Система автоматически считает стоимость (credits) и проверяет ограничения

## 1. Просмотр правил игры

### 1.1 Навигация по разделам правил

**Цель**: Предоставить удобный справочник по правилам без необходимости листать книгу.

**Сценарий**:
1. Пользователь открывает раздел «Правила».
2. Видит многоуровневое оглавление, сгруппированное по блокам:

   **Основные механики**
   - Характеристики бойцов (M, WS, BS, S, T, W, I, A, Ld, Cl, Wil, Int)
   - Последовательность хода (Priority, Movement, Shooting, Fighting, Morale)
   - Бросание кубиков, модификаторы, тесты

   **Движение**
   - Стандартное движение, бег, карабканье
   - Трудная местность, препятствия
   - Charge, Retreat

   **Стрельба**
   - Выбор цели, линия видимости
   - Типы атак (Rapid Fire, Blast, Template, Toxin и др.)
   - Броня и сохранение
   - Статусы: Pinned, Seriously Injured, Out of Action

   **Ближний бой**
   - Инициирование рукопашной схватки
   - Разрешение атак, оружие Versatile / Melee
   - Групповые атаки

   **Моральный дух и тесты**
   - Cool test, Bottle test
   - Fleeing, Rally

   **Кампания**
   - Структура кампании (Dominion, Law & Misrule и др.)
   - Доход территорий, Gang Rating
   - Post-battle sequence (Experience, Advancement, Injuries, Trading Post)
   - Outlanders и Hired Guns


   **Банды и фракции**
   - Описание каждой банды (Goliath, Escher, Cawdor, Orlock, Van Saar, Delaque, Enforcers, Corpse Grinder Cult и др.)
   - Специальные правила фракций
   - Доступные типы бойцов и их базовые характеристики

   **Оружие и снаряжение**
   - Классификация оружия (Basic, Pistol, Heavy, Close Combat, Special)
   - Профили оружия (Range, Acc S/L, Str, AP, D, Ammo, Traits)
   - Wargear и аксессуары
   - Trading Post и Black Market

   **Специальные правила и ключевые слова**
   - Алфавитный список спецправил (Knockback, Rending, Shock, Toxin, Blast, Rapid Fire и т.д.)

3. Клик по разделу — открывается страница с правилом.
4. Внутри правила — гиперссылки на связанные термины.

**Функциональность**:
- Полнотекстовый поиск по всем правилам
- Закладки / избранное (сохраняются в профиле)
- Фильтр по источнику: Core Rules, Book of Peril, Book of Ruin, House of… и т.д.
- Режим «шпаргалки» — одна страница с самыми используемыми таблицами
- Версия для печати каждого раздела

### 1.2 Справочник по фракциям и бойцам

**Цель**: Быстро найти характеристики конкретного бойца или банды.

**Сценарий**:
1. Пользователь переходит в «Правила → Банды».
2. Выбирает фракцию, например **Goliath**.
3. Видит:
   - Лор и описание банды
   - Типы бойцов: Forge Boss, Forge Champion, Stimmer, Bully, Gonner, Juve (Bruiser)
   - Для каждого: базовые характеристики, начальная стоимость, доступное снаряжение, спецправила
4. Клик на тип оружия — переход к полному профилю оружия.

### 1.3 Справочник по оружию и снаряжению

**Сценарий**:
1. Пользователь открывает «Правила → Оружие и снаряжение».
2. Фильтрует по категории: Pistol / Basic / Heavy / Close Combat / Grenades / Wargear.
3. Дополнительно фильтрует по доступности для конкретной фракции.
4. Таблица с профилями: Range, Acc (S/L), Str, AP, D, Ammo, Traits.
5. Клик на Trait — всплывающее описание правила.

## 2. Ведение кампании

### 2.1 Создание кампании

**Цель**: Организовать совместную кампанию для нескольких игроков.

**Сценарий**:
1. Один игрок (Arbitrator) нажимает «Новая кампания».
2. Заполняет форму:
   - Название кампании
   - Тип: Dominion Campaign / Law & Misrule / Succession Campaign / Narrative
   - Стартовый бюджет банд (стандарт: 1000 credits)
   - Список участников (приглашение по ссылке или email)
   - Стартовые территории (если применимо)
3. Система создаёт кампанию и рассылает приглашения.
4. Каждый участник принимает приглашение и привязывает свою банду.

### 2.2 Создание банды

**Цель**: Собрать банду строго в соответствии с правилами выбранной фракции.

**Сценарий**:
1. Игрок открывает «Мои банды → Создать банду».
2. Выбирает фракцию (например, **House Escher**).
3. Система загружает правила фракции:
   - Разрешённые типы бойцов и их лимиты (не более 2 Champions, минимум 3 Gangers и т.д.)
   - Стартовый бюджет и специальные правила фракции
4. Игрок вводит название банды и начинает добавлять бойцов.

   **Добавление бойца**:
   - Выбирает тип: Leader / Champion / Ganger / Juve / Specialist
   - Вводит имя; система показывает базовые характеристики и стоимость
   - Выбирает оружие из разрешённого для данного типа списка:
     - Категории: Primary, Secondary, Close Combat, Grenades, Wargear
     - Для каждой категории — допустимые лимиты на количество
     - Стоимость обновляется в реальном времени
   - Попытка добавить недопустимое оружие → предупреждение
   - «Добавить» — боец появляется в ростере

5. Счётчик credits обновляется после каждого изменения.
6. Система блокирует сохранение при:
   - Превышении бюджета
   - Нарушении лимитов типов бойцов
   - Отсутствии Leader
7. Банда сохраняется и привязывается к кампании.

### 2.3 Просмотр и редактирование банды

**Сценарий**:
1. Игрок открывает свою банду. Сводный экран:
   - **Gang Rating** и **Wealth** (накопленные credits)
   - Список бойцов со статусом (Active / Recovery / Dead / Captured) и снаряжением
   - Список территорий и история боёв
2. Клик на бойца — карточка бойца:
   - Характеристики с учётом всех Advancements
   - Снаряжение, накопленный XP, пройденные Advancements
   - Постоянные ранения (Lasting Injuries) и навыки
3. Доступные действия: изменить снаряжение, добавить бойца, изменить статус бойца.

### 2.4 Арсенал банды (Gang Stash)

**Цель**: Отслеживать снаряжение, не выданное конкретным бойцам.

**Сценарий**:
1. В карточке банды есть раздел «Арсенал».
2. Снятое с бойца оружие перемещается в стэш, а не исчезает.
3. Из стэша снаряжение переназначается другому бойцу (с проверкой допустимости).
4. Покупки на Trading Post / Black Market добавляются сначала в стэш.


### 2.5 Генерация миссии

**Цель**: Автоматически подобрать сценарий для очередного сражения.

**Сценарий**:
1. Arbitrator открывает «Кампания → Новое сражение».
2. Выбирает участников боя (2 или более банды).
3. Нажимает «Сгенерировать миссию» — система:
   - Учитывает тип кампании
   - Учитывает соотношение Gang Rating участников
   - Случайно выбирает сценарий из подходящего пула (Tunnel Skirmish, Gang Moot, Ambush, Raid, Stand-off, Border Dispute и т.д.)
   - Определяет условия победы и специальные правила сценария
   - Рассчитывает Underdog bonus при значительной разнице Gang Rating
4. Карточка миссии содержит:
   - Название и описание сценария
   - Условия победы для каждой стороны
   - Особые правила сценария
   - Рекомендуемые размер стола и тип ландшафта
   - Underdog bonus (если есть)
5. Игроки принимают или перегенерируют миссию.
6. После принятия миссия фиксируется, создаётся запись предстоящего боя.

### 2.6 Ввод результатов сражения (Post-Battle Sequence)

**Цель**: Провести полную процедуру после боя строго по правилам.

**Сценарий**:
1. После боя участники открывают запись боя.

**Шаг 1 — Результат**:
- Указывается победитель или ничья
- Отмечаются выполненные условия победы каждой стороны

**Шаг 2 — Судьба бойцов** (для каждого Out of Action):
- Игрок вводит результат броска на таблице Lasting Injury
- Система применяет результат автоматически:
  - **Full Recovery** — боец активен
  - **Captured** — боец захвачен, помечается как Captured у противника
  - **Permanent Injury** — к карточке добавляется ранение (-1 M, -1 T, потеря глаза и т.д.)
  - **Critical Injury** — требует дорогостоящей операции, иначе смерть
  - **Killed in Action** — боец удаляется из ростера

**Шаг 3 — Опыт**:
- Игрок вводит XP каждому участвовавшему бойцу (за участие, убийства, выполнение задач)
- При достижении порога Advancement — предлагается выбор:
  - Улучшение характеристики (+1 WS, +1 S, +1 BS и т.д.)
  - Новый навык из доступных категорий для данного типа бойца
  - Повышение в звании (Juve → Ganger, Ganger → Specialist)

**Шаг 4 — Доход**:
- Система рассчитывает доход от всех территорий банды
- Начисляет credits за победу / выполненные условия по правилам сценария
- Показывает итоговый баланс credits

**Шаг 5 — Захваченные бойцы**:
- Банда-победитель решает: продать захваченного за credits или удержать как заложника
- Банда побеждённого может выкупить своего бойца (стоимость = половина стоимости бойца)

**Шаг 6 — Trading Post** (опционально):
- Игрок покупает снаряжение в пределах доступных credits
- Ограничения по допустимости снаряжения применяются автоматически

2. После завершения всех шагов:
   - Карточки бойцов обновляются
   - Gang Rating пересчитывается
   - В историю кампании добавляется запись о бое
   - Турнирная таблица обновляется

### 2.7 Управление территориями

**Сценарий**:
1. В разделе кампании — карта или список территорий.
2. Каждая территория имеет:
   - Название и тип (Mine Workings, Settlement, Drinking Hole, Collapsed Dome и т.д.)
   - Доход (credits за цикл) и специальный бонус
   - Текущий владелец
3. После боя за территорию Arbitrator меняет владельца.
4. В начале каждого нового цикла система автоматически начисляет доход от территорий.

### 2.8 Наём Hired Guns

**Сценарий**:
1. Игрок открывает «Банда → Hired Guns».
2. Список доступных наёмников с характеристиками и стоимостью найма.
3. Добавляет наёмника к банде на текущий бой (временный найм).
4. Наёмник отображается в ростере отдельно, не входит в постоянный Gang Rating.
5. После боя наёмник автоматически удаляется из ростера.

### 2.9 Турнирная таблица и история кампании

**Сценарий**:
1. Раздел «Кампания → Турнирная таблица».
2. Все банды кампании, отсортированные по:
   - Gang Rating
   - Количеству побед / поражений
   - Контролируемым территориям (для Dominion)
   - Очкам кампании (для Succession)
3. Полная история всех боёв с датами, участниками и результатами.
4. Arbitrator может завершить кампанию и зафиксировать победителя.

## 3. Создание произвольного ростера

### 3.1 Создание нового ростера

**Цель**: Собрать банду для разовой игры или теоркрафтинга без привязки к кампании.

**Сценарий**:
1. Пользователь открывает «Ростеры → Новый ростер».
2. Вводит название, выбирает фракцию, указывает лимит credits (или «без ограничений»).
3. Система применяет правила выбранной фракции.
4. Пользователь собирает банду по тому же принципу, что в п. 2.2.
5. Дополнительные опции:
   - Добавление Hired Guns сразу при создании
   - Выбор Alliance (если правила позволяют)
   - Режим без ограничения credits для тестирования любых комбинаций

### 3.2 Конструктор бойца

**Сценарий**:
1. Нажимает «Добавить бойца».
2. Выбирает тип — только типы, разрешённые для данной фракции.
3. Вводит имя.
4. **Выбор оружия** — слоты соответствуют типу бойца:
   - У Ganger (Escher): 1 Basic или 2 Pistols как Primary, 1 CCW как Secondary
   - В каждом слоте отображается только допустимое оружие
   - Стоимость каждого пункта показывается сразу
5. **Выбор Wargear**: Armour, Grenades, Personal Equipment, Status Items с автоматическими ограничениями на дубли.
6. **Навыки** (для симуляции опытной банды): фильтруются по категориям, разрешённым для данного типа бойца.
7. Итоговая стоимость бойца обновляется в реальном времени.

### 3.3 Валидация ростера

| Проверка | Описание |
|----------|----------|
| ✅ Leader | Ровно один Leader в банде |
| ✅ Champions | Лимит не превышен (обычно не более 2) |
| ✅ Gangers | Минимальное количество соблюдено |
| ✅ Бюджет | Общая стоимость не превышает лимит credits |
| ✅ Оружие бойца | Только допустимое для данного типа бойца |
| ✅ Кол-во оружия | Соблюдены ограничения на количество единиц |
| ✅ Hired Guns | Не превышен допустимый лимит наёмников |

- Нарушения подсвечиваются красным у соответствующего бойца или поля
- Сводная панель ошибок вверху ростера
- Сохранение заблокировано до устранения критических ошибок

### 3.4 Экспорт и печать ростера

Варианты экспорта:
- **PDF** — форматированный лист банды для печати (A4)
- **Краткий PDF** — только характеристики и снаряжение, без описаний правил
- **Ссылка для просмотра** — публичная ссылка (read-only)
- **JSON** — для интеграции со сторонними инструментами

### 3.5 Управление несколькими ростерами

Раздел «Ростеры» показывает все ростеры пользователя: фракция, Gang Rating, дата изменения.

Доступные действия:
- Дублировать ростер (основа для нового варианта)
- Архивировать / удалить
- Конвертировать в банду кампании (с сохранением всего состава)

## 4. Управление пользователями

### 4.1 Профиль пользователя

- Регистрация по email или через OAuth (Google)
- Профиль: ник, аватар, любимая фракция
- История всех кампаний и ростеров

### 4.2 Роли в кампании

| Роль | Возможности |
|------|-------------|
| **Arbitrator** | Создание кампании, управление территориями, генерация и фиксация миссий, разрешение споров |
| **Player** | Управление своей бандой, просмотр других банд, ввод результатов своей стороны |
| **Observer** | Просмотр кампании в режиме read-only |

---

## 5. Нефункциональные требования

- **Оффлайн-доступ**: правила и собственные ростеры кэшируются для работы без интернета; автоматическая синхронизация при восстановлении соединения
- **Версионирование данных**: при выходе FAQ/errata приложение уведомляет о затронутых бандах; старые ростеры сохраняются с пометкой об изменениях правил
- **Мультиплатформенность**: полная функциональность в браузере на desktop и mobile, адаптивный интерфейс для планшета за игровым столом
- **Безопасность данных**: каждый игрок видит чужие банды только в режиме просмотра; редактирование только своих данных

## 6. Приоритеты реализации

### MVP (Минимально жизнеспособный продукт)
1. Справочник правил (статический контент, базовые разделы)
2. Создание и валидация ростера для одной фракции (например, Goliath)
3. PDF-экспорт ростера

### Версия 1.0
4. Все основные фракции (6–8 домов: Goliath, Escher, Cawdor, Orlock, Van Saar, Delaque)

6. Post-battle sequence (XP, ранения, доход)
7. Генерация миссий

### Версия 2.0
8. Все фракции включая Outlanders, культы, Enforcers
9. Hired Guns и Alliance
10. Полный справочник правил с поиском и закладками
11. Полная история кампании и статистика
12. Мобильная оптимизация и оффлайн-режим
