> Система управления кампаниями для настольной игры **Necromunda: Gang Wars** от Games Workshop

[![Tech Stack](https://img.shields.io/badge/stack-React%20%2B%20Node.js%20%2B%20PostgreSQL-blue)](#технологии)

---

## 📋 Описание проекта

Веб-приложение для автоматизации ведения кампаний Necromunda:
- **Справочник правил** с поиском и офлайн-доступом
- **Построитель ростера** с автоматическим расчётом Gang Rating и валидацией
- **Управление кампанией** — территории, боевые записи, post-battle sequence
- **Совместная игра** — Arbitrator + Players в одной кампании онлайн

## 📖 Справочник правил

Статический HTML-справочник открывается с файла `index.html`. В корне лежат
только главная страница и документация.

```
Necromunda Digital/
├── index.html              главная
├── README.md, PRD.md, SCENARIOS.md, TECH_STACK.md
├── pages/                  страницы справочника и стили
│   ├── core-rules.html
│   ├── gangs.html
│   ├── roster-example.html
│   └── styles.css
├── tools/                  сборка и исходный текст из PDF
│   ├── build_gangs.py
│   ├── _qa.py
│   ├── gangs_raw.txt
│   └── rules_raw.txt
└── Правила/                исходные PDF
```

| Файл | Раздел | Источник |
| --- | --- | --- |
| `pages/core-rules.html` | Основные правила | `Правила/SKIRMUNDA.pdf` |
| `pages/gangs.html` | Правила банд (19 списков) | `Правила/GANGS0_3.pdf` |
| `pages/roster-example.html` | Пример стартового ростера Каудор на 1000 кредитов | SKIRMUNDA + список Каудор |

Структура разделов и навигация — на русском, тексты правил приведены в оригинале.
Общие стили лежат в `pages/styles.css`.

Раздел каждой банды свёрнут в три блока: «Бойцы банды» (внутри сворачивается и
каждая карточка отдельно), список снаряжения и «Экипировка банды» — профили
оружия и описания клановой экипировки. Развёрнутыми остаются только состав
банды, особые правила и доступ к навыкам.

В списках снаряжения название предмета раскрывается по клику и показывает его
профиль: таблицу характеристик для оружия, описание с ценой для брони и
снаряжения, характеристики бойца для питомцев и ездовых животных.

Ссылки на карточки бойцов (из состава банды и из профилей питомцев) ведут внутрь
свёрнутых блоков, поэтому в `gangs.html` есть небольшой скрипт: при переходе по
якорю он раскрывает всю цепочку блоков над целью. Всё остальное работает на
чистом HTML и CSS.

Страница банд собирается скриптом `tools/build_gangs.py`, поэтому правки в неё
нужно вносить через скрипт. Профили он берёт из двух источников: раздела Trading
Post в `tools/rules_raw.txt` и таблиц оружия самой банды в `tools/gangs_raw.txt`
(профиль банды приоритетнее). Скрипт печатает долю позиций, для которых профиль
найден:

```bash
python tools/build_gangs.py
```

Проверить целостность собранной страницы (потери текста, дубли `id`, битые
якоря, число ячеек в таблицах):

```bash
python tools/_qa.py
```
